Data
MODEL
Data structures and persistent storage
👥
User Model
Stores user name, email, hashed password, role, and organisation ID.
🏢
Organisation Config
Database host, port, name, username. Password stored encrypted — never plaintext.
🕓
Query History
Stores each query: the question, generated SQL, AI explanation, and chart type.
🐘
Platform Database
PostgreSQL — managed by SQLense. Stores users, config, query history.
🏢
Organisation Database
PostgreSQL — owned by the company. Never touched by SQLense storage. Read-only via AI.
Role-Based Access Control
🧑‍💼 Admin
  • Connect & configure organisation database
  • Create and manage employee accounts
  • SQL Workspace — full CRUD, DDL & DML
  • Transaction control — Commit / Rollback
  • Access AI Analytics
👤 Employee
  • Ask natural language business questions
  • View AI-generated charts and insights
  • Read-only access — no write operations
  • View personal query history
🏢
Organisation Isolation
Each organisation's data is completely isolated. One admin's employees can never access another organisation's data.
🔒
Privacy-First Design
Company business data never leaves the organisation's own database. SQLense only reads — never copies or stores business records.
🛡️
Secure by Default
Passwords hashed with bcrypt · Database credentials encrypted with Fernet · JWT tokens expire in 60 minutes.
